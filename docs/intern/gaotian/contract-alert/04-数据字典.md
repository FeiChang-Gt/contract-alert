# 合同预警模块 数据字典

## 一、字段枚举说明
| 字段名 | 枚举值 | 含义 |
| --- | --- | --- |
| alert_level | 1 | 合同状态正常（剩余>30天） |
| alert_level | 2 | 到期预警（剩余8~30天） |
| alert_level | 3 | 紧急预警（剩余≤7天） |
| is_renewed | 0 | 未续签 |
| is_renewed | 1 | 已完成续签 |
| is_renewed | 2 | 不再续签 |
| del_flag | 0 | 数据正常、未删除 |
| del_flag | 1 | 逻辑删除 |

## 二、公共字段说明
- create_time：数据创建时间，插入时自动赋值
- update_time：数据更新时间，变更时自动刷新
- create_by：数据创建人
- update_by：数据更新人

## 三、约束与索引说明
1. emp_no 员工工号：全局唯一约束，禁止重复录入
2. 主键 id：自增 bigint 类型
3. 索引：工号唯一索引、到期日期查询索引、预警等级筛选索引
