# 合同到期预警模块 接口测试文档

---

## 一、业务背景
本模块属于员工全生命周期管理子模块，覆盖员工入职、转正、调动、续签、调薪、离职全流程，专门用于管理员工劳动合同到期预警与续签跟进。

- 对应生命周期：续签
- 开发仓库：esd-app / esd 模块
- 建议包名：com.wits.di.hrc.esd.intern.renewal
- 能力维度：日期计算、统计、Excel 导出

---

## 二、业务对象
核心实体：员工劳动合同台账（esd_contract_alert）

---

## 三、接口测试文档

### 1. 合同预警信息录入接口
- 接口说明：新入职员工劳动合同信息录入，自动查重、计算剩余天数、分级预警。
- 请求地址：http://localhost:8080/contract/add

### 4.1 每天自动跟新预警等级
- 接口说明：每天0点自动跟新预警的等级
- 预警规则：>30天绿、≤30天黄、≤7天红
- 请求地址：http://localhost:8080/contract/refreshLevel
- 请求方式：GET

### 返回数据

"message": "刷新成功",
"data": null
