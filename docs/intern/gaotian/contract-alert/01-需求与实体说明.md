# 合同到期预警模块 需求与实体说明

## 一、业务背景
本模块属于员工全生命周期管理子模块，覆盖员工入职、转正、调动、续签、调薪、离职全流程，专门用于管理员工劳动合同信息，实现合同到期自动分级预警，提前提醒人事完成合同续签工作，规避用工风险。

- 对应生命周期：续签
- 开发仓库：`esd-app / esd` 模块
- 建议包名：`com.wits.di.hrc.esd.intern.renewal`
- 能力维度：日期计算、统计、Excel导出

## 二、业务对象
核心实体：员工劳动合同台账（`esd_contract_alert`）

## 三、业务场景说明
1. 新入职员工劳动合同信息录入
2. 合同到期自动计算剩余天数、分级预警
3. 合同续签跟进状态更新、预警状态关闭
4. 预警等级统计、Excel批量导出（≤500行）
5. 员工调动、离职时合同状态归档

## 四、核心业务规则
1. 录入合同开始日期、合同到期日期，同一员工工号仅允许存在一条有效合同记录（逻辑删除除外）。
2. 系统自动计算：当前日期距离合同到期日的剩余天数 `remain_days`。
3. 自动划分3档预警等级：
    - 剩余天数 ＞30天：等级1 正常状态（绿色）
    - 8天 ≤ 剩余天数 ≤30天：等级2 提前预警（黄色）
    - 剩余天数 ≤7天：等级3 紧急预警（红色）
4. 标记合同已续签后，预警状态自动解除；标记为「不再续签」时须填写跟进备注信息。
5. 数据支持逻辑删除（`del_flag=1`），保留操作痕迹。
6. 公共字段 `create_time/update_time/create_by/update_by` 由系统自动维护。

## 五、数据表结构设计
表名：`esd_contract_alert`

| 字段名称 | 数据类型 | 字段注释 | 约束说明 |
| --- | --- | --- | --- |
| id | bigint | 主键ID，自增 | 主键，非空，自增 |
| emp_no | varchar(50) | 员工工号，唯一标识 | 非空，唯一索引 |
| emp_name | varchar(100) | 员工姓名 | 非空 |
| dept_name | varchar(100) | 所属部门 | 可空 |
| contract_start | date | 合同开始日期 | 非空 |
| contract_end | date | 合同到期日期 | 非空 |
| remain_days | int | 距离到期剩余天数 | 可空，系统自动计算 |
| alert_level | tinyint | 预警等级 | 1=正常 2=预警 3=紧急，默认1 |
| is_renewed | tinyint | 跟进状态 | 0=未续签 1=已续签 2=不再续签，默认0 |
| follow_note | varchar(255) | 跟进备注 | 不再续签时必填 |
| create_time | datetime | 数据创建时间 | 默认 CURRENT_TIMESTAMP |
| update_time | datetime | 数据更新时间 | 默认 CURRENT_TIMESTAMP，更新自动刷新 |
| create_by | bigint | 创建人ID | 可空 |
| update_by | bigint | 更新人ID | 可空 |
| del_flag | tinyint | 逻辑删除标记 | 0=正常 1=删除，默认0 |

## 六、索引设计
1. 主键索引：`PRIMARY KEY (id)`
2. 唯一索引：`uk_emp_no`（`emp_no`），保证同一员工仅一条有效合同记录
3. 普通索引：`idx_alert_level`（`alert_level`），快速筛选不同预警等级数据
4. 普通索引：`idx_contract_end`（`contract_end`），提升到期日期批量查询效率

## 七、数据字典（枚举说明）
1. 预警等级 `alert_level`
    - 1：正常（＞30天，绿色）
    - 2：预警（8-30天，黄色）
    - 3：紧急（≤7天，红色）
2. 跟进状态 `is_renewed`
    - 0：未续签
    - 1：已续签
    - 2：不再续签
3. 逻辑删除 `del_flag`
    - 0：正常
    - 1：已删除

## 八、接口清单（必须实现）
1. 录入接口：新增合同预警台账；（工号姓名不为空，工号不重复，合同开始日期和结束日期不为空，且开始日期小于结束日期）
2. 分页查询接口：查询员工合同信息；（工号姓名模糊查询，部门，预警，续签精准查询，按最新创建时间排序）
3. 更新跟进接口：更新续签状态、续签备注信息（不续签必写），是否续签
4. 等级统计接口：按预警等级统计数量,设置每天自动跟新预警等级
5. Excel导出接口：支持导出≤500行数据(用文件流把excel传给浏览器下载)
